# invosData 市場洞察分析報告 Skill

## 你的任務

使用者上傳了一份嬰幼兒奶粉（或快消品）市場數據報告，要求你針對指定品牌產出一份 Word 格式的「invos 市場洞察分析報告」。

**固定輸出：四章 .docx 報告**
- 第一章：嬰幼兒奶粉市場整體現況
- 第二章：品牌專屬市場洞察（5 則，每則含數據發現 / 市場洞察 / 突破方向）
- 第三章：invos 三大服務策略建議
- 第四章：策略重點一覽（彙總表格）

---

## Step 1：提取報告數據

用 Python 讀取上傳的 PPTX 全文：

```bash
python3 -c "
import zipfile, re
path = '<uploaded_pptx_path>'
with zipfile.ZipFile(path) as z:
    slides = sorted([n for n in z.namelist() if re.match(r'ppt/slides/slide\d+\.xml', n)])
    for i, s in enumerate(slides, 1):
        xml = z.read(s).decode('utf-8', errors='ignore')
        text = re.sub(r'<[^>]+>', ' ', xml)
        text = re.sub(r'\s+', ' ', text).strip()
        print(f'=== P{i} ===')
        print(text[:1500])
        print()
"
```

整理以下數據（記錄頁碼備用）：

| 類別 | 要找的指標 |
|------|-----------|
| **市場規模** | 整體銷售額 YoY、購買人數 YoY、人均購買次數、單次金額 |
| **通路** | 各通路（藥局/電商/婦嬰）銷售佔比、人流佔比、YoY 變化 |
| **品牌競爭** | 目標品牌 vs 主競品的銷售額 YoY、市佔率變化 |
| **各階奶粉** | 一/三/四階的銷售佔比、人流 YoY、銷售額 YoY |
| **新舊客** | 新客人流 YoY、舊客人流 YoY、新舊客銷售佔比 |
| **目標品牌細節** | 各 SKU 的買家數、銷售額、購買次數、單次金、通路分佈 |
| **競品細節** | 主要競品的通路佔比、增長特徵、客群行為 |
| **跨品類** | 奶粉買者的其他購買品類（大樹相關性分析等）|

## Step 2：分析架構（四章內容）

### 第一章：整體市場現況

依序撰寫以下 5 個小節：

**1.1 市場成長結構**
- 核心問題：成長是靠「人變多」還是「買更多次」？
- 必含表格：整體銷售額 / 購買人數 / 人均次數 / 單次金，含 YoY（需附實際數值，非僅百分比）
- 重點敘事：點明成長驅動結構（新客萎縮 vs 舊客深化的比值）
- ⚠️ **指標市場意義解讀（必寫）**：表格之後必須逐一解釋四項指標對市場的代表意義：
  1. **銷售額（Sales Amount）— 市場整體的健康指標**：成長率代表市場處於上升期還是飽和期，在成熟市場中維持 5%+ 的成長代表消費需求仍然強勁
  2. **購買人數（Number of Buyers）— 市場滲透率與廣度**：人數下滑意味著新客獲取遇到瓶頸或輕度使用者流失，代表成長並非來自「廣度」擴張，而是靠現有消費者貢獻
  3. **人均次數（Purchase Frequency）— 品牌黏著度與習慣**：反映消費者使用習慣的養成程度，與訂閱制或品牌忠誠度相關，維持住購買頻率是穩定市場的基石
  4. **單次金額（Transaction Value）— 消費升級與單價**：上升通常有三個原因：(1)價格調漲——受通膨或原料成本影響 (2)大包裝銷售——消費者傾向一次買更多 (3)高值化商品——消費者願意選擇更高端的產品
  5. **綜合分析（粗體段落）**：用一段粗體文字總結市場趨勢定性（如「質變重於量變」），說明核心動能（哪項指標主導成長）、市場警示（客群篩選方向）、策略建議方向（Up-selling / 購買頻率 / 重新吸引流失客群）

**1.2 各階奶粉表現**（若品類不分階段，則改為子品類/功能訴求分類）
- 哪個階段（或子品類）是成長引擎？哪個受外部因素衝擊？
- 必含表格：各階銷售市佔 / 人流滲透 / YoY

**1.3 通路分佈與競爭格局**
- 藥局 / 電商 / 婦嬰通路的份額移動趨勢
- 若有非授權通路（如酷澎）問題，需特別說明
- ⚠️ **通路 × 品牌競爭定位（必寫）**：通路表格之後必須加一段「通路 × 品牌」分析，說明：
  1. 目標品牌在哪些通路有上架，主要銷售管道為何
  2. 各通路年對年佔比變化（哪些通路份額提升、哪些下滑）
  3. **各通路內的主要競品**：明確指出目標品牌在每個重要通路面對的前 2-3 名競品及其市佔，例如「康是美最熱銷的競品為 BHK's（佔比 15%）和倍適」「寶雅則以新普利（20%）、我的健康日記（12%）為主」
  4. 點出哪些競品是該通路下可優先關注的對象

**1.4 品牌競爭態勢**
- 市場中高端 / 中端 / 平價三層競爭格局
- 點名快速成長的競品及其增長驅動因素

**1.5 新舊客買者狀態（NES 分析）**
- ⚠️ **NES 市場意義解讀（必寫）**：不只呈現數字，必須解釋數字對市場的結構性意義：
  1. **開頭定調**：用一句話定義市場處於什麼階段（如「存量競爭」），明確指出經營重點應從「積極獲新」轉向「精準留存與會員經營」
  2. **NES 三項指標逐一解讀**（必須含實際人數）：
     - **New（品類新進買者）**：人數 + YoY → 解讀市場滲透率擴張是否趨緩、新客獲取成本是否墊高
     - **Existing（品類既有買者）**：人數 + YoY → 解讀核心消費者群體穩定度，點出這群人是市場的「壓艙石」、人均貢獻度遠高於新客
     - **Sleeping（品類流失買者）**：人數 + YoY → 解讀「漏水速度」是否改善，以及是否仍處於「淨流出」（流失 > 新增）
  3. **市場意義總結**：串聯三項指標描繪市場格局（如「新客微降、舊客持平、流失改善→存量競爭」），說明品牌間競爭本質已從「誰吸引更多新人」轉為「誰能讓人持續回購」
  4. 補充新/舊客人均貢獻差異（次數、單次金、年均消費）、特定年齡層的品類黏著度差異

### 第二章：品牌專屬市場洞察

**⚠️ 洞察品質標準（最重要的判斷依據）：**

> 當你寫完一則洞察，問自己：「這個洞察如果換成其他奶粉品牌，還適用嗎？」
> 如果適用，就不夠具針對性，必須重寫。
> 洞察必須根植於目標品牌的獨特數據表現，其他品牌看不到相同現象。

**撰寫 5 則洞察，每則格式固定：**

```
洞察標題：用有張力的「比喻型命名」，如「陷阱型成長」「商品化漂移」「升級斷層」
▶ 數據發現：具體數字 + 與市場均值 / 競品的對比，說明「異常」在哪裡
▶ 市場洞察：解釋這個異常背後的消費者行為邏輯或結構性原因
▶ 突破方向：改變品牌現有認知的行動路徑，要有具體落地感
```

**洞察發掘方向（從以下角度找「只屬於這個品牌」的數字異常）：**
- 銷售額成長 vs 市佔率 / 購買人數的背離
- 單次金額異常（過低 / 過高 / 快速下滑）
- 某通路佔比極端集中（>80% 在單一通路）
- 新客流失速度超過市場自然衰退速度
- 某 SKU 的舊客增長爆發但新客同步萎縮（黏性信號）
- 一階 → 三階升級流失：消費者有沒有跟著品牌走？
- 電商空白：主競品都在做、這個品牌卻缺席的通路
- 非授權通路滲透：是否有定價秩序問題？
- 跨品類購買信號：奶粉買者還買什麼？

### 第三章：invos 三大服務策略建議

每個服務對應 3–4 個具體方案，每個方案格式：
**◆ 方案名稱**（一行）+ 執行內容（3–5 句，約 80–120 字，有具體數字）

**invos Insight｜市場機會洞察**
- 服務定義：賦能品牌智慧決策，建立可落地執行的策略
- 適合對應：品牌健康指數監測、競品崛起解碼、升級轉換率分析、通路結構報告
- 每個方案要說明「追蹤什麼指標」「多久提供一次」「協助品牌做什麼決策」

**invos Media｜精準獲客轉換**
- 服務定義：高效鎖客，快速驗證，驅動全場景行銷擴散
- 適合對應：精準受眾圈選（依發票行為）、廣告投放時機、轉換漏斗優化
- 每個方案要說明「圈選哪個受眾」「在什麼時機 / 什麼平台投放」「預期什麼效果」

**invos API｜全通路會員整合**
- 服務定義：將單次消費顧客加入私域流量池，個人化經營
- 適合對應：跨通路資料整合、升級旅程自動化推播、訂閱制 / 補貨提醒、非授權通路識別
- 每個方案要說明「整合哪些數據來源」「觸發什麼動作」「帶來什麼留存效果」

## Step 3：生成 Word 文件

讀取 `references/docx-template.js` 作為程式碼起點，用 Node.js + docx 套件生成 .docx。

```bash
cd /sessions/<session-id>/docx_work
npm install docx 2>/dev/null
node generate_insight_report_<brand>.js
```

**文件設計規範：**

| 項目 | 規格 |
|------|------|
| 頁面尺寸 | A4（11906 × 16838 DXA）|
| 邊距 | 上下左右各 1440 DXA（2.54cm）|
| 預設字體 | Arial |
| 標題色 | `2E75B6`（深藍）|
| 封面副標 | `品牌名稱 品牌專屬市場洞察與 invos 服務策略建議` |
| 洞察框 | 每則洞察用淺灰底表格包裹（fill: `F0F4F8`）|
| 服務建議表格 | 左欄：服務名稱（深色底，白字）；右欄：方案內容 |
| 彙總表格 | 三行，標題欄用各服務色（Insight 綠 `16A34A`、Media 青 `0891B2`、API 紫 `7C3AED`）|
| 數據表格 | 灰色邊框（`CCCCCC`），表頭淺藍底（`D5E8F0`）|

## Step 4：驗證輸出

```bash
# 確認文件可以用 pandoc 讀出標題結構
pandoc <output_path>.docx -t markdown 2>/dev/null | grep "^#" | head -20
```

確認：
- [ ] 四章標題都存在
- [ ] 5 則洞察各有「數據發現 / 市場洞察 / 突破方向」
- [ ] 三大服務各有 3–4 個方案
- [ ] 所有數字有具體來源（不是空泛描述）
- [ ] 每則洞察能通過「換品牌還適用？」的針對性測試
