# invosData 市場洞察分析報告 Skill

## 你的任務

使用者上傳了一份嬰幼兒奶粉（或快消品）市場數據報告，要求你針對指定品牌產出一份 Word 格式的「invos 市場洞察分析報告」。

**固定輸出：四章 .docx 報告**
- 第一章：嬰幼兒奶粉市場整體現況
- 第二章：品牌專屬市場洞察（5 則，每則含數據發現 / 市場洞察 / 突破方向）
- 第三章：invos 三大服務策略建議
- 第四章：策略重點一覽（彙總表格）

---

## Step 1：提取報告數據

用 Python 讀取上傳的 PPTX 全文：

```bash
python3 -c "
import zipfile, re
path = '<uploaded_pptx_path>'
with zipfile.ZipFile(path) as z:
    slides = sorted([n for n in z.namelist() if re.match(r'ppt/slides/slide\d+\.xml', n)])
    for i, s in enumerate(slides, 1):
        xml = z.read(s).decode('utf-8', errors='ignore')
        text = re.sub(r'<[^>]+>', ' ', xml)
        text = re.sub(r'\s+', ' ', text).strip()
        print(f'=== P{i} ===')
        print(text[:1500])
        print()
"
```

整理以下數據（記錄頁碼備用）：

| 類別 | 要找的指標 |
|------|-----------|
| **市場規模** | 整體銷售額 YoY、購買人數 YoY、人均購買次數、單次金額 |
| **通路** | 各通路（藥局/電商/婦嬰）銷售佔比、人流佔比、YoY 變化 |
| **品牌競爭** | 目標品牌 vs 主競品的銷售額 YoY、市佔率變化 |
| **各階奶粉** | 一/三/四階的銷售佔比、人流 YoY、銷售額 YoY |
| **新舊客** | 新客人流 YoY、舊客人流 YoY、新舊客銷售佔比 |
| **目標品牌細節** | 各 SKU 的買家數、銷售額、購買次數、單次金、通路分佈 |
| **競品細節** | 主要競品的通路佔比、增長特徵、客群行為 |
| **跨品類** | 奶粉買者的其他購買品類（大樹相關性分析等）|

## Step 2：分析架構（四章內容）

### 第一章：整體市場現況

依序撰寫以下 5 個小節：

**1.1 市場成長結構**
- 核心問題：成長是靠「人變多」還是「買更多次」？
- 必含表格：整體銷售額 / 購買人數 / 人均次數 / 單次金，含 YoY
- 重點敘事：點明成長驅動結構（新客萎縮 vs 舊客深化的比值）

**⚑ 四指標市場意義解讀（每次必寫，不可省略）**

數據表格之後，必須用一段文字說明這四個數字背後對市場的意涵。不只是「YoY 幾 %」，而是解釋這個組合代表什麼結構性訊號。依照以下四個維度逐一詮釋：

| 指標 | 市場意義角度 | 解讀重點 |
|------|------------|---------|
| **銷售額** | 市場整體健康度 | 市場是否仍在成長期？成長幅度是否高於通膨基準？ |
| **購買人數** | 市場滲透廣度 / 新客獲取能力 | 人數下滑 → 新客獲取遇瓶頸，廣度在收縮；上升 → 品類仍在擴張客群 |
| **人均次數** | 品牌黏著度與習慣養成 | 頻次提升 → 消費習慣強化，忠誠客貢獻提升；停滯或下降 → 黏性弱，易流失 |
| **單次金額** | 消費升級 / 高值化信號 | 上升驅動：①價格調漲 ②大包裝銷售 ③消費者主動選高端；需說明判斷依據 |

**解讀撰寫原則：**
1. 先說「數字組合的整體結論」（一句話）：例如「這是一個典型『質變重於量變』的市場」
2. 再逐一說明每個指標的市場涵義（每條 2–3 句）
3. 最後給出「綜合策略警示」：對品牌而言，這個市場結構意味著什麼風險或機會？

**範例結構（參考，依實際數字調整）：**
```
整體結論：銷售額 +X% 的成長，完全由單次金額拉動，購買人數微降，代表市場進入「深耕現有買家」的型態。

▶ 銷售額 +X%：市場仍具成長動能，但需確認成長是否仰賴單一驅動。
▶ 購買人數 -X%：新客獲取出現瓶頸，市場廣度開始收縮。留存策略的重要性上升。
▶ 人均次數 +X%：消費習慣正在養成，核心客戶的購買規律在強化。
▶ 單次金額 +X%：消費者傾向購買更高單價的品項（可能來自大包裝或高端升級）。
              需進一步確認：是品牌主動漲價，還是品類組合自然高值化？

⚠ 策略警示：若購買人數持續下滑，市場廣度萎縮的壓力將在 1–2 年內壓縮成長空間。
           品牌應在深化高單價的同時，布局新客獲取來源，避免進入「縮量高價」的困境。
```

**1.2 各階奶粉表現**
- 哪個階段是成長引擎？哪個階段受出生率衝擊？
- 必含表格：各階銷售市佔 / 人流滲透 / YoY

**1.3 通路分佈與競爭格局**
- 藥局 / 電商 / 婦嬰通路的份額移動趨勢
- 若有非授權通路（如酷澎）問題，需特別說明

**⚑ 逐通路競品點名（每次必寫，不可省略）**

在呈現各通路份額數據後，必須從**目標品牌的視角**，逐一點名每個主要通路中值得優先關注的競品。不能只說「市場競爭激烈」，要說清楚「誰在哪個通路搶你的份額」。

**撰寫原則：**
1. 選出目標品牌市佔前三的通路，各別點名在該通路份額最高的 2–3 個競品
2. 區分兩種優先程度：
   - **主要競爭對手**：在同一通路份額與目標品牌相近或更高，直接搶奪同一批消費者
   - **可優先關注的競品**：在該通路份額較小、但增速快，或目標品牌在該通路佔比低、具滲透空間
3. 每個通路一句話結論，說明品牌在此通路的競爭處境

**範例結構（參考，依實際數字調整）：**
```
▶ 康是美：[品牌]的主要競爭對手為 [競品A]（佔比X%）和 [競品B]（佔比X%），
         兩者合計壓縮 [品牌] 在此通路的成長空間。

▶ 寶雅：[競品C]、[競品D]、[競品E] 為 [品牌] 在寶雅通路下可優先關注的競品，
       目前份額雖低，但寶雅通路整體 YoY +X%，值得提前布局應對。

▶ momo：[品牌] 在 momo 的主要威脅來自 [競品F]，其份額從 X% 提升至 X%，
        是 [品牌] 電商份額被稀釋的主要來源。
```

**判斷「值得關注」的競品條件（至少符合其一）：**
- 在該通路的份額 YoY 增速顯著高於市場平均
- 目標品牌在該通路市佔偏低（<5%），競品已占據明顯優勢位置
- 競品客群（NES 新客來源）與目標品牌重疊度高

**1.4 品牌競爭態勢**
- 市場中高端 / 中端 / 平價三層競爭格局
- 點名快速成長的競品（如明治、卡洛塔妮）及其增長驅動因素

**1.5 新舊客買者狀態（NES 分析）**
- 新客 vs 舊客人流對比，說明結構性趨勢
- 結論：品牌成長重點應往「深化 LTV」還是「擴大人流」

**⚑ NES 三群市場意義解讀（每次必寫，不可省略）**

呈現完 N / E / S 人數與 YoY 之後，必須加一段說明這個組合對市場代表什麼策略訊號。依照以下三個維度詮釋：

| 指標 | 市場意義角度 | 解讀重點 |
|------|------------|---------|
| **N 品類新進買者** | 市場獲新能力 | 新客增 → 品類仍在擴張，市場紅利未耗盡；新客減 → 市場觸頂訊號，獲新成本上升 |
| **E 品類既有買者** | 留存與品牌黏著度 | 既有買者穩定是市場基本盤健康的核心指標；下滑代表品牌難以留住回頭客 |
| **S 品類流失買者** | 流失健康度 | S 絕對值縮小 → 市場整體流失改善，消費者黏性提升；S 擴大 → 品類認同在弱化 |

**解讀撰寫原則：**
1. 先說「整體人數增減的主要原因來自哪一群」（一句話定位）
2. 逐一說明 N / E / S 各自的市場涵義（每條 1–2 句）
3. 最後給出「市場競爭階段判斷」：點明市場現在是「擴張期 / 存量競爭期 / 衰退期」，以及對應的經營重心轉移方向

**常見市場階段對應邏輯（參考）：**
```
N ↑ E ↑ S ↓  →  擴張期：積極獲新仍是主軸，品牌投資重點在觸及與轉換
N ↓ E ↑ S ↓  →  存量競爭期：市場已難靠新人頭成長，留存與 LTV 深化才是主戰場
N ↓ E ↓ S ↑  →  衰退警示：品類整體吸引力下降，需品類教育或重新定位
N ↑ E ↓ S ↑  →  結構不穩：有新人進來但舊客在離開，品牌體驗或價格可能有斷層
```

**範例結構（參考，依實際數字調整）：**
```
整體人數 -X%，主要來自新客（N）下滑 X%，既有買者（E）大致維持，流失買者（S）絕對值縮小 X%。

▶ N 新客 -X%：品類獲取新受眾的能力減弱，可能反映品類認知觸頂或競品瓜分入口。
▶ E 既有買者 ±X%：核心消費群穩固，短期流失風險低。
▶ S 流失買者縮減 X%：流失情況有所改善，留存率在回升。

⚑ 市場階段判斷：市場已進入「存量競爭」階段。
  經營重點應從「積極獲新」轉向「精準留存與會員經營」，
  重點布局：舊客回購機制、高頻補貨提醒、升級路徑引導。
```

### 第二章：品牌專屬市場洞察

**⚠️ 洞察品質標準（最重要的判斷依據）：**

> 當你寫完一則洞察，問自己：「這個洞察如果換成其他奶粉品牌，還適用嗎？」
> 如果適用，就不夠具針對性，必須重寫。
> 洞察必須根植於目標品牌的獨特數據表現，其他品牌看不到相同現象。

**撰寫 5 則洞察，每則格式固定：**

```
洞察標題：用有張力的「比喻型命名」，如「陷阱型成長」「商品化漂移」「升級斷層」
▶ 數據發現：具體數字 + 與市場均值 / 競品的對比，說明「異常」在哪裡
▶ 市場洞察：解釋這個異常背後的消費者行為邏輯或結構性原因
▶ 突破方向：改變品牌現有認知的行動路徑，要有具體落地感
```

**洞察發掘方向（從以下角度找「只屬於這個品牌」的數字異常）：**
- 銷售額成長 vs 市佔率 / 購買人數的背離
- 單次金額異常（過低 / 過高 / 快速下滑）
- 某通路佔比極端集中（>80% 在單一通路）
- 新客流失速度超過市場自然衰退速度
- 某 SKU 的舊客增長爆發但新客同步萎縮（黏性信號）
- 一階 → 三階升級流失：消費者有沒有跟著品牌走？
- 電商空白：主競品都在做、這個品牌卻缺席的通路
- 非授權通路滲透：是否有定價秩序問題？
- 跨品類購買信號：奶粉買者還買什麼？

### 第三章：invos 三大服務策略建議

每個服務對應 3–4 個具體方案，每個方案格式：
**◆ 方案名稱**（一行）+ 執行內容（3–5 句，約 80–120 字，有具體數字）

**invos Insight｜市場機會洞察**
- 服務定義：賦能品牌智慧決策，建立可落地執行的策略
- 適合對應：品牌健康指數監測、競品崛起解碼、升級轉換率分析、通路結構報告
- 每個方案要說明「追蹤什麼指標」「多久提供一次」「協助品牌做什麼決策」

**invos Media｜精準獲客轉換**
- 服務定義：高效鎖客，快速驗證，驅動全場景行銷擴散
- 適合對應：精準受眾圈選（依發票行為）、廣告投放時機、轉換漏斗優化
- 每個方案要說明「圈選哪個受眾」「在什麼時機 / 什麼平台投放」「預期什麼效果」

**invos API｜全通路會員整合**
- 服務定義：將單次消費顧客加入私域流量池，個人化經營
- 適合對應：跨通路資料整合、升級旅程自動化推播、訂閱制 / 補貨提醒、非授權通路識別
- 每個方案要說明「整合哪些數據來源」「觸發什麼動作」「帶來什麼留存效果」

## Step 3：生成 Word 文件

讀取 `references/docx-template.js` 作為程式碼起點，用 Node.js + docx 套件生成 .docx。

```bash
cd /sessions/<session-id>/docx_work
npm install docx 2>/dev/null
node generate_insight_report_<brand>.js
```

**文件設計規範：**

| 項目 | 規格 |
|------|------|
| 頁面尺寸 | A4（11906 × 16838 DXA）|
| 邊距 | 上下左右各 1440 DXA（2.54cm）|
| 預設字體 | Arial |
| 標題色 | `2E75B6`（深藍）|
| 封面副標 | `品牌名稱 品牌專屬市場洞察與 invos 服務策略建議` |
| 洞察框 | 每則洞察用淺灰底表格包裹（fill: `F0F4F8`）|
| 服務建議表格 | 左欄：服務名稱（深色底，白字）；右欄：方案內容 |
| 彙總表格 | 三行，標題欄用各服務色（Insight 綠 `16A34A`、Media 青 `0891B2`、API 紫 `7C3AED`）|
| 數據表格 | 灰色邊框（`CCCCCC`），表頭淺藍底（`D5E8F0`）|


確認：
- [ ] 四章標題都存在

- [ ] 三大服務各有 3–4 個方案
- [ ] 所有數字有具體來源（不是空泛描述）
