# invosData 通路佈局 × 客群配對策略矩陣 Skill

## 與「品牌成長策略版」的差異

| 維度 | 品牌成長策略版 (bcg-analysis) | 通路佈局找對的人版 (本 skill) |
|------|---------------------------|--------------------------|
| **讀者** | 品牌經理/行銷主管/決策層 | 通路業務/通路行銷/電商營運/事業部主管 |
| **核心問題** | 品牌整體健不健康？成長動能在哪？ | 100+ 產品如何在對的通路找到對的人？ |
| **BCG 軸線** | 品牌掌握度 × 客群規模與成長潛力 | 客群掌握度 × 通路規模與潛力 |
| **五欄定義** | 通路整體/品類新客/舊客升級/競品轉換/電商 | 各通路（momo/康是美/寶雅）/舊客/競品客 |
| **話術方向** | 由上往下：市佔率、NES、競品威脅 | 由下往上：這通路的人在買什麼、該放什麼 SKU |
| **看完後行動** | 決定大方向和預算配置 | 調整通路的產品組合和執行方案 |

**使用場景建議：** 品牌成長策略版用在前期提案或高階會議，建立專業信任感；本版用在與執行團隊的工作坊或具體行動規劃會議，讓通路負責人直接拿去用。

## 你的任務

使用者上傳了一份市場數據報告 PPTX，要求你從「通路佈局找對的人」角度生成四頁 BCG 策略投影片。

**核心原則：話術重心是「100+ 產品如何在對的通路找到對的人」**
- 每個通路的人在比較不同品牌 — 產品佈局不能複製貼上
- 瓶頸指向「人找不到/留不住」的根因
- 機會指向「如何用數據找到」
- 行動建議聚焦產品×通路配對

**固定輸出：四頁深色主題 PPTX（用 pptxgenjs 生成）**
- Slide 1：封面頁（深色背景 + 中央圖示與「行動建議」標題）
- Slide 2：通路×客群 BCG 矩陣圖 + 右側策略定位說明
- Slide 3：為什麼找不到對的人 × 如何用數據找到（5 欄 × 2 列）
- Slide 4：通路佈局行動方案 × invosData 幫你在每個通路找到對的人（5 欄 × 2 列）

## Step 1：讀取並分析報告

用 `python3` + `zipfile` 提取報告 PPTX 所有頁面的文字：

```bash
python3 -c "
import zipfile, re, sys
path = '<uploaded_pptx_path>'
with zipfile.ZipFile(path) as z:
    slides = sorted([n for n in z.namelist() if re.match(r'ppt/slides/slide\d+\.xml', n)])
    for i, s in enumerate(slides, 1):
        xml = z.read(s).decode('utf-8', errors='ignore')
        text = re.sub(r'<[^>]+>', ' ', xml)
        text = re.sub(r'\s+', ' ', text).strip()
        print(f'=== P{i} ===')
        print(text[:1200])
        print()
"
```

閱讀全部頁面後，重點整理**以通路為主軸**的資訊：

| 分析維度 | 要找的資訊 |
|---------|-----------|
| **各通路客數與趨勢** | 每個通路的買家人數、YoY、新舊客比例 |
| **各通路 RPC（客單價）** | 每通路 RPC + 全市場均消金額比較 |
| **各通路競品** | 每個通路的前 2-3 競品是誰（注意：通路間競品不同） |
| **回購率** | 各通路首購→回購轉化率 |
| **流失結構** | 流失客中多少是「停買品類」vs「轉買競品」 |
| **舊客價值** | 舊客 vs 新客的人均年消費、購頻、交叉購買 |
| **競品交叉** | 跨品牌購買（交叉購買）數據 |
| **非授權通路** | 酷澎等水貨通路的客數、客單、品牌新客比例 |
| **品牌自有通路** | 91APP 等品牌通路佔比 |

## Step 2：建立通路×客群配對框架

以「**通路規模與潛力 × 客群掌握度**」定義 BCG 的五個欄位：

| 欄 | 標題 | 副標 | BCG 象限 |
|----|------|------|---------|
| 1 | [電商主力通路] | 高單價 / 組合包 / 進階功能 | Cash Cow |
| 2 | [藥妝通路 A] | 明星單品 / 試用裝 / 首購導流 | Question Mark |
| 3 | [藥妝通路 B] | 差異化品項 / 打不同競品 | Question Mark |
| 4 | 舊客回購×產品延伸 | 留存深化 / 交叉銷售 / 升級 | Star |
| 5 | 競品客轉換×通路防守 | [主競品] 對策 | Star + Dogs |

> 欄位定義需依報告中的實際通路結構調整，但保持 5 欄，且每欄明確指出「該放什麼類型的產品」。

**BCG 矩陣軸線定義（通路×客群版）：**
- **X 軸（左→右）**：客群掌握度（不知道誰在買 → 知道誰在買）
- **Y 軸（上→下）**：通路規模大但成長受限 → 通路規模小但潛力高

象限位置與直覺語言：
```
Dogs                    | Cash Cow
（看得到人流，抓不住客人）  （最知道誰在買，但人正在走）
────────────────────────┼────────────────────────
Question Mark           | Star
（新人一直來，但都只買一次）（已知道是誰，能主動出擊）
```

**每個象限的標題要用「客戶直覺語言」**，例如：
- 🐮 momo：「最知道誰在買，但人正在走」
- 🐶 酷澎：「看得到人流，抓不住客人」
- ❓ 康是美：「新人一直來，但都只買一次」
- ⭐ 舊客+競品客：「已知道是誰，能主動出擊」

## Step 3：填寫四頁投影片的內容

### Slide 1：封面頁

固定版面，確認品牌名稱和報告期間正確。

### Slide 2：BCG 四象限 + 右側說明框

**標題格式：** `{品牌}{品類}｜通路佈局 × 客群配對策略矩陣`
**副標題：** `{報告期間}｜100+ 產品如何在對的通路找到對的人？`

**四象限要點（各 2 點，粗體小標 + 說明句）：**

| 象限 | 要點 1 重心 | 要點 2 重心 |
|------|-----------|-----------|
| Dogs（非授權通路） | 客數暴增但 RPC 極低 + 低價吸引非品牌力 | 水貨通路無法做產品×客群配對 |
| Cash Cow（電商主力） | 品牌「對的人」最集中 + RPC/均消最高 | 客數下滑但流失原因是停買非轉競品 |
| Question Marks（藥妝） | 天然品牌體驗入口 + 高新客比但低回購 | 第二藥妝通路的競品差異 |
| Stars（舊客+競品客） | 舊客人均價值 vs 新客 + 留存率問題 | 競品交叉買者可識別可轉換 |

**右側四個策略說明框（每框：標題 + 一句描述 + 2 條關鍵數據）**

### Slide 3：為什麼找不到對的人 × 如何用數據找到

**標題：** `{品牌}{品類}｜為什麼 100+ 產品還是找不到對的人？`

每欄 × 每列 **3 條 bullet**（各附頁碼引用）：

**為什麼找不到對的人**：瓶頸全部指向「人找不到/留不住」的根因
**如何用數據找到**：機會全部指向「如何用數據找到對的人」

### Slide 4：通路佈局行動方案 × invosData 方案

**標題：** `{品牌}{品類}｜通路佈局行動方案 × invosData 幫你在每個通路找到對的人`

**行動建議（每欄 3 條）**，聚焦產品×通路配對：
- 電商主力：放高單價組合包 + 定期購/補貨提醒 + 流失客品類喚醒
- 藥妝 A：只放明星單品做入口 + QR Code 導流線上 + 針對該通路競品的貨架策略
- 藥妝 B：放差異化品項 + 導流品牌通路 + 觀測份額決定加碼/回收
- 舊客：RFM 分層交叉銷售 + 識別交叉銷售路徑 + 忠誠回饋
- 競品客+防守：精準轉換 + 不投入非授權通路 + 品牌通路獨家 SKU

每欄附 2 個 tag（如「產品配對」「留客機制」「首購入口」「導流橋樑」等）

**invosData 方案標題：** `▶ invosData 幫你在每個通路找到對的人`

每欄 3 個服務模組（invos Insight / Media / API），每個 bullet 聚焦「幫你在這個通路找到誰」。

## Step 4：生成 PPTX

讀取 `references/pptx-template.js` 作為程式碼基礎。

```bash
cd /sessions/<session-id>/docx_work && npm install pptxgenjs 2>/dev/null || true
node generate_bcg_channel_<brand>.js
```

**設計規範與 bcg-analysis 一致：**

| 項目 | 規格 |
|------|------|
| 投影片尺寸 | LAYOUT_WIDE（13.3" × 7.5"）|
| 背景色 | `21253A`（深藍黑）|
| 字型 | Microsoft JhengHei（微軟正黑體）|
| 字型大小 | 僅 12/10/8 三種 |
| 行距 | 1.5 倍 |
| 文字色 | 白色為主，報告來源引用維持灰色 |
| 封面頁 | 深色背景 + 中央圖示（白色長條圖 icon）+ 大字「行動建議」|
| 欄數 | 固定 5 欄 |
| 每條 bullet 頁碼 | inline 小字灰斜體，格式 `[句子+"  ", "報告 p.X"]` tuple |
