## 報告結構

### 第一章：益生菌市場整體現況
- 1.1 市場成長結構（銷售額 +8%、購買人數 +5%、人均次數 1.8 次、單次金 NT$2,008）
- 1.2 通路分佈與競爭格局（好市多 22%、葡眾 11%、momo 8%）
- 1.3 品牌競爭態勢（威德 16%、善存 +71% 快速崛起）
- 1.4 新舊客買者狀態 NES 分析（新客 -4%、舊客 +22%、流失 +18%）
- 1.5 輕中重度買者 HML 分析（重度買者貢獻 50% 營收）

### 第二章：威德品牌專屬市場洞察（5 則）
1. **「單通路依賴症」** — 96% 銷額鎖死好市多，品牌無腹地可退
2. **「新客荒」** — 新客 -16%，首購佔比 44.7%→30.8%，獲客引擎熄火
3. **「善存侵蝕效應」** — 善存攔截好市多潛在新客，威德新客水源被掐
4. **「舊客撐盤假象」** — 舊客 +23% 掩蓋輕度用戶流失與頻率下降
5. **「檔期天花板」** — 放寬限購無效，促銷已無法拉動增長

### 第三章：invos 三大服務策略建議
- **invos Insight** — 新客健康指數監測、善存競爭解碼、檔期效率追蹤
- **invos Media** — 好市多潛在新客觸達、電商小包裝種草、新客 90 天留存
- **invos API** — 全通路私域識別池、檔期間補貨提醒、品類離開預警系統
